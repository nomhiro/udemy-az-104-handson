# L0-2 ハンズオンの環境を準備する

この講座のハンズオンを始める前に、Azure portal の言語とサブスクリプションを確かめ、使いすぎに気づくための予算とアラートを作ります。続いて、Cloud Shell を開いて教材のリポジトリを置き、以後のレッスンで使う後片付けの型（リソース グループごと削除する）を練習します。

- 所要時間: 約20分
- 費用: Cloud Shell のファイルを残すために、ストレージ アカウントを1つ作ります。Cloud Shell のマシンは無料ですが、**ストレージには通常の料金がかかります**（金額は Azure の料金のページで確かめてください）
- このレッスンで作ったもののうち、**予算と Cloud Shell のストレージは、講座のあいだ残しておきます**。練習のリソース グループは最後に削除します

## 前提

- Azure のサブスクリプションと、そのサブスクリプションの **所有者** のロール（以後のレッスンで、ロールの割り当てや予算の作成をするため）
- サインインできる Microsoft のアカウント

## このレッスンで作るもの

| 種類 | 名前 | 残すか |
|---|---|---|
| 予算 | `budget-az104`（毎月 5,000 円・実際のコストが 80% でメール） | 残す |
| Cloud Shell のストレージ | Cloud Shell が作るリソース グループとストレージ アカウント（名前は自動） | 残す |
| リソース グループ | `rg-az104-l02`（練習用） | 手順7で削除 |

## 手順

### 1. Azure portal の言語を確かめる

1. Azure portal（https://portal.azure.com）にサインインします
2. 右上の歯車（設定）を選び、［言語と地域］を開きます
3. 言語が「日本語」であることを確かめます。違うときは「日本語」を選び、［適用］を選びます

この講座の画面と語りは、日本語の Azure portal に合わせています。

### 2. サブスクリプションとディレクトリを確かめる

1. 上の検索欄に「サブスクリプション」と入れ、候補の「サブスクリプション」を選びます
2. 一覧に、使うサブスクリプションがあることを確かめます。［自分の役割］の列が「所有者」になっていることも確かめます
3. 右上の歯車（設定）の［ディレクトリとサブスクリプション］で、いまのディレクトリ（テナント）を確かめます。サブスクリプションが複数のディレクトリにあるときは、使うディレクトリに切り替えます

### 3. 予算とアラートを作る

予算は、使いすぎに気づくための警報です。**しきい値を超えるとメールで知らせますが、予算そのものがリソースを止めることはありません。**

1. 手順2のサブスクリプションを開き、左のメニューの［コスト管理］>［予算］を選びます
2. 一覧の上の絞り込み欄に `az104` と入れてから、［＋ 追加］を選びます。［予算を作成する］の［予算の詳細］と［予算額］に次のとおりに入れて、［次へ］を選びます
   - 名前: `budget-az104`
   - リセット期間: 月単位（作成日と有効期限は既定のまま）
   - 金額: 5000（通貨はサブスクリプションの通貨。金額は自分で決めてかまいません。下に表示される提案額やこれまでのコストは、人によって違います）
3. ［通知の設定］の［警告条件］で、種類を「実際のコスト」、予算の割合を「80」にします（金額の欄に 4,000 と出ます）。［アラートの受信者 (メール)］に自分のメール アドレスを入れて、［作成］を選びます
4. 予算の一覧（絞り込み欄に `az104`）に `budget-az104` があることを確かめます

- コストのデータは通常 8〜24時間で反映され、予算は24時間ごとに評価されます。作った直後にメールは届きません
- アラートのメールが迷惑メールに入らないよう、`azure-noreply@microsoft.com` を承認済みの送信者に入れておくと安心です

### 4. Cloud Shell を開き、ストレージを作る

1. 上のバーの Cloud Shell のアイコンを選びます
2. 「Azure Cloud Shell へようこそ」で［Bash］を選びます
3. ［作業の開始］で［ストレージ アカウントをマウントする］を選び、［ストレージ アカウントのサブスクリプション］で手順2のサブスクリプションを選んで、［適用］を選びます
4. ［ストレージ アカウントをマウントする］で［ストレージ アカウントが作成されます］を選び、［次へ］を選びます。`cloud-shell-storage-<リージョン>` というリソース グループと、ストレージ アカウント・ファイル共有が作られ、ターミナルが開きます（リージョンと名前は自動で決まります）

以前に［ストレージ アカウントは不要です］を選んだことがあるときは、Cloud Shell のツール バーの［…］>［設定］>［ユーザー設定のリセット］を選んでから、1. からやり直します。

ターミナルの文字が小さいときは、［…］>［設定］>［テキスト サイズ］で「大」を選べます。

- Cloud Shell は、操作が無いまま20分たつと切れます。切れたら、Cloud Shell を開き直します
- Cloud Shell が作ったリソース グループ（とその中のストレージ アカウント）を削除すると、Cloud Shell に保存したファイルが消えます。講座のあいだは残しておきます

### 5. 教材のリポジトリを置く

Cloud Shell（Bash）で、次のコマンドを順に入れます。

```bash
git clone https://github.com/nomhiro/udemy-az-104-handson.git
cd udemy-az-104-handson
ls lessons
```

`lessons` の中に、章ごとのフォルダーが並べば完了です。次に Cloud Shell を開いたときも、このフォルダーは残っています（`ls` で `clouddrive` と `udemy-az-104-handson` が出ます）。

### 6. 練習のリソース グループを作る

以後のハンズオンでは、レッスンで作るものを1つのリソース グループに入れ、最後にリソース グループごと削除します。その型を練習します。

1. 上の検索欄に「リソース グループ」と入れ、候補の「リソース グループ」を選びます
2. 一覧の絞り込み欄に `rg-az104` と入れ、まだ何も無いことを確かめます
3. ［＋ 作成］を選び、次のとおりに入れて、［レビューと作成］>［作成］を選びます
   - サブスクリプション: 手順2のサブスクリプション
   - リソース グループ: `rg-az104-l02`
   - リージョン: (Asia Pacific) Japan East
4. リソース グループの一覧の絞り込み欄に `rg-az104` と入れ、`rg-az104-l02` があることを確かめます（出ないときは［最新の情報に更新］を選びます）

### 7. 練習のリソース グループを削除する（後片付けの型）

1. `rg-az104-l02` を開き、［概要］で［リソース グループの削除］を選びます
2. 確認の欄にリソース グループの名前を入れて［削除］を選び、「削除の確認」でもう一度［削除］を選びます
3. リソース グループの一覧の絞り込み欄に `rg-az104` と入れ、「フィルターに一致する リソース グループ はありません」と出ることを確かめます（削除には数分かかることがあります。［最新の情報に更新］を選びます）

Cloud Shell でも確かめられます。

```bash
az group list --query "[?starts_with(name, 'rg-az104')].name" -o tsv
```

何も出なければ、片付けは終わりです。

## うまくいかないとき

- **［予算］で［＋ 追加］が選べない**: サブスクリプションで、所有者か共同作成者のロールが要ります
- **Cloud Shell に［作業の開始］の画面が出ない**: 以前に設定したことがあります。ストレージなしで使っていたときは、［設定］>［ユーザー設定のリセット］を選んでやり直します
- **Cloud Shell の作成でエラーになる**: サブスクリプションで Microsoft.CloudShell のリソース プロバイダーが登録されているかを確かめます（サブスクリプション >［リソース プロバイダー］）
