# udemy-az-104-handson

Udemy 講座「【AZ-104対策】Azure管理者 座学＋ハンズオン講座 Microsoft Azure Administrator」のハンズオン教材です。各レッスンの `README.md` に、Azure portal での操作と Cloud Shell のコマンドを番号つきの手順で載せています。

## 前提

- Azure のサブスクリプション。リソースを作ると料金がかかります
- サブスクリプションの **所有者** のロール。ロールの割り当てを試すレッスンがあるためです
- Microsoft Entra ID の章の一部（動的グループ、セルフサービス パスワード リセット）には、Microsoft Entra ID P1 または P2 のライセンスが要ります（試用版で試せます）
- Azure portal の言語は日本語にしています（portal の右上の歯車 >「言語と地域」）。動画の画面と同じ表示で進められます

## 使い方

1. Azure portal の上部のアイコンから Cloud Shell を開き、Bash を選びます
2. このリポジトリを clone します

   ```bash
   git clone https://github.com/nomhiro/udemy-az-104-handson.git
   cd udemy-az-104-handson
   ```

3. 取り組むレッスンのフォルダの `README.md` を開き、手順1から進めます

## レッスンの決まり

- **どのレッスンも、新しいリソース グループを作るところから始め、リソース グループごと削除して終わります。** 前のレッスンで作ったものには頼りません
- 前提のリソース（仮想ネットワークや VM など）が要るレッスンは、`shared/` の Bicep で数分で用意します。手順は各レッスンの README にあります
- リソース グループの名前は `rg-az104-<レッスン>`（例: `rg-az104-l22`）です

## 費用と後片付け

- 各レッスンの最後の手順で、リソース グループを削除します。削除したら、portal の「リソース グループ」の一覧から消えたことを確かめてください
- 消し忘れに気づけるように、サブスクリプションに予算とアラートを設定しておくことをおすすめします（はじめにの章のレッスンで扱います）
- すぐに削除できないものがあります。Recovery Services コンテナーは、バックアップのデータが論理削除の状態で14日間残り、その間はコンテナーを削除できません。該当するレッスンの README に手順を書いています
- 次のコマンドで、このハンズオンで作ったリソース グループが残っていないかを確かめられます

  ```bash
  az group list --query "[?starts_with(name, 'rg-az104-')].name" -o tsv
  ```

## 構成

```
udemy-az-104-handson/
├── lessons/   # レッスンごとの README（章のフォルダ > レッスンのフォルダ）
└── shared/    # 前提のリソースを用意する Bicep
```

レッスンは講座の制作に合わせて順に追加します。
